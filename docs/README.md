# Screenshots

Drop your screenshots in this folder so they show up in the main README.

Take these three (on Mac: press **Cmd + Shift + 4**, then drag to select an area):

| Save as | What to capture |
|---------|-----------------|
| `home.png` | Your homepage (top section with the hero) |
| `dashboard.png` | The admin dashboard with the charts and a table |
| `gallery.png` | The gallery page (or a programme page with photos) |

Save each file into this `docs/` folder with the exact name above. The main
README already links to them, so once they're here they'll display automatically.
Then commit and push:

```bash
git add docs/
git commit -m "Add screenshots"
git push
```
